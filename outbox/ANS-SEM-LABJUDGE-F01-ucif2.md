## (a) 四范式碰撞图：**pass**

**成立性判定：成立，同构判定准确。**

| 范式 | 证书形态 | 同构对象 | 判定 |
|---|---|---|---|
| P1 区间算术 | 外向舍入包络 | 联邦级"名"（定界而非定值） | 准确 |
| P2 SAT 证明 | DRAT/LRAT 可机检轨迹 | schema 机检 | 准确 |
| P3 形式化助手 | 类型论内核证书 | fp 互锚（内核↔命题） | 准确，但需注意 fp 互锚在 P3 中实为 *kernel↔statement* 而非 *证明↔反证* 对偶 |
| P4 PINN 失败模式 | 残差/守恒违例谱 | 退火路径（失败面即退火能谷边界） | 成立但**同构强度弱于前三者** |

要点：
- P1–P3 的同构是**结构同构**（证书对象可被独立检查器判定），可直接接入联邦元结构。
- P4 与退火路径的对应是**类比同构**（失败模式↔能谷边界的测度论对应尚未形式化）。建议在图中标注 P4 为 *dashed edge*，避免误当已证同构使用。
- 联邦级名=schema 机检=fp 互锚=退火路径四者在"**可被第三方复核的判定对象**"这一层确实同型；四范式碰撞图作为 **glue 层**成立。

## (b) M4/M5/M6 镜像律候选：**pass（均够格入册）**

- **M4 延拓律**（curriculum ≡ 退火 ≡ 同伦）：够格。三者统一于"**参数化形变下不变量保持**"，是可陈述、可反例化的律，非隐喻。建议补充**反例条款**：当形变路径不连通（拓扑断点）时律失效——这恰是 P4 失败模式的入口。
- **M5 TCB 最小化律**（求解器不可信 + 小型检查器 + 检查器须被检查）：够格，且与 (c) FM-015 构成律-实例对。三层递归（solver⊄TCB, checker∈TCB, meta-checker∈TCB）本身即审计锚的必要条件。
- **M6 审计锚律**（内容寻址为第三方复核前置）：够格。注意合取关系：内容寻址是**必要非充分**——需外加"锚定对象=被复核对象"的等式约束，否则可被选择性锚定规避。建议入册时写入此边界。

三条均达**洞见级**：可独立陈述、可被违反、违反有可观测后果。

## (c) FM-015 检查器缺检模式：**pass（入 FM-LIB）**

- drat-trim 实案（检查器接受恶意假证书）是**真实、可复现、有公开依据**的缺检模式，符合 FM-LIB 入册标准。
- 归类建议：**FM-015 ∈ 缺检模式（silent-accept）**，与"错误拒绝"分离建档。
- 须标注限制：该实案针对特定版本/补丁条件；入册时应记录**版本指纹与复现环境**，否则退化为传闻级。
- 与 M5 的联动：FM-015 正是"检查器须被检查"未落实时的典型失效，二者互锚，建议在 FM-LIB 中加交叉引用。

## (d) 元问题 v2 重构 + META-PIPE-01：**pass**

- 元问题 v2 五要素（机检化 / 可申诉 / 域限 / 跨范式 / 制度化授予-维持-降级-撤销）覆盖了信任级生命周期的**授予-维持-撤销**闭环，且"可申诉"与"域限"是 v1 缺失的关键补丁，重构方向正确。
- META-PIPE-01 七段流水线（候选→框架伴生→双轮→域限正式→镜像锚定→证书化→对抗复核）**自洽**：
  - "框架伴生"与"双轮"保证了候选对象不被单框架绑架；
  - "域限正式"是防止跨域越权授予的关键闸门；
  - "对抗复核"与 (c) 的 FM-015 形成闭环（复核者本身须过 M5）。
- **批准为联邦元结构**，附两点：
  1. 建议在 PIPE-01 明确**降级回路**（正式→候选的回退）的操作主体，否则"撤销"仅有名义而无执行者。
  2. 元问题 v2 中"可申诉"须给出**时限与裁决机构**，否则不可操作。

## (e) F-X1 区间证书实验：**pass（附效力边界降级）**

**通过理由**：6/6 PASS 且具备形式要件——外向舍入包络 |marg|≤1.55e-11、cost 宽 1.32e-13、f64/f80 双包含，均为**可机检的证书数据**，非存在性论断。

**降级/限制条件（必须写入备案）**：
1. **效力层级 = 求值层非存在性层**：本实验证明的是"给定表述下求值落在包络内"，**不构成**对底层存在性/可解性的证明。这一点报告已自陈，评审确认并**要求不要在任何下游引用中把它升格为存在性证书**。
2. **亚 LP 松弛由认证不可行性解释**：此解释合法，但它把"松弛为何存在"从经验观察升格为认证结论——须核对**不可行性证书本身是否过 META-PIPE-01 的对抗复核**，否则该解释仅是与主结论并行的附注，不可作为主结论的支撑。
3. **f64/f80 双包含**是强项，但需注明**未覆盖 f128/任意精度**的域限，避免被读作"跨精度普遍成立"。
4. 建议 F-X1 以 **`pass@eval-layer`** 标签入册，与 `pass@existence-layer` 分列，防止层级混淆。
