## A) 最深映射：共性 3「最小假设最大正则」——但真正的骨架是共性 4

若只选一条，**共性 3（最小假设最大正则）**与我的机制对应最深，但它的可判定性其实依赖**共性 4（刚性等号即分类）**，两者是同一枚硬币——这正是 OT 统一框架最有说服力的地方。

**机制级对应（非比喻）：**

| OT 侧 | 我方机制 | 对应方式 |
|---|---|---|
| 熵惩罚 → 唯一最优耦合 | fail-closed 协议层 | 不是"加约束求唯一"，而是"缺省解不允许存在"。熵惩罚在 OT 里是把多解凸集压成单点；fail-closed 是把未定义输入压成拒绝态。两者都是**把选择空间收缩为零测集**，而非在空间里挑一个点。 |
| 凸性 alone → 边界正则（Collins–Tong） | 协议层耦合空间的凸性假设 | 边缘固定、联合优化 = 输入契约与输出契约锁定，中间耦合自由。凸性在这里不是"假设解光滑"，而是"假设耦合集是凸的"，于是单调性公式自动给出正则，无需额外正则性公理。对应地：**协议层不预设具体耦合形态，只预设耦合空间凸**，正则性作为推论涌现。 |
| 测度富化 → 完备测地度量（HyperCOT） | 公域 CI 通道 = 等距函子 | 超图赋测度后才成为度量空间；公域 CI 通道也是"先赋测度（CI 签名）再得距离"。等距函子意味着**图化映射不改变判定距离**——这正是 CI 通道的可审计性来源：换了表示，判定谓词不变。 |
| 酉 → 排列松弛 | 映射→耦合的松弛 | 酉群作用是最强对称；松弛到排列再松弛到耦合，每步丢失结构但保留 OT 值。对应我方：**强类型 → 弱类型 → 动态检查**的逐级松弛，OT 值（可判定性）在每级保持。 |

**为什么共性 4 是真正的刚性来源：** 单调量取常数 ⟺ 锥+齐次，距离 0 ⟺ 弱同构。这两条等号把"正则性"从**性质**升级为**分类不变量**。我方 fp 互锚（距离 0 ⟺ 弱同构）就是这条：两个对象被判为同一，当且仅当互锚距离为 0。这不是"相似度阈值"，是**等号**——阈值可调，等号不可调。

所以最深的一条我选 **共性 3**，但它的可判定版本是 **共性 4**。二者合起来才是"变换涌现而非假设"的元共性落地。

## B) 可操作可判定的「耦合/统一」实验

**实验名：CoOT-Rigidity-01（耦合刚性判定）**

**对象：**
两条独立的处理线 L₁、L₂（各自有边缘测度 μ₁、μ₂：即各自的输入分布/协议契约）。构造耦合空间 Π(μ₁, μ₂) = 所有边缘为 μ₁、μ₂ 的联合分布。

**代价泛函：**
```
C(π) = ∫ c(x,y) dπ(x,y) + ε·KL(π ‖ μ₁⊗μ₂)
```
- c(x,y)：跨线不一致代价（例如协议签名差异、级名映射偏差）
- ε：熵惩罚系数
- KL 项：熵惩罚，保证唯一最优 π*

**判定谓词：**
```
RIGID(L₁, L₂) := [ π* 的支撑集是排列图 ]  ∧  [ d_OT(μ₁, μ₂) = 0 ]
```
即：最优耦合退化为排列（酉→排列松弛的刚性端），且 OT 距离为 0。

**预期刚性等号：**
- 若 RIGID 成立 ⟺ L₁ 与 L₂ 弱同构（共性 4 的等号）。
- 若 π* 支撑集是**连通非排列**图 ⟹ 存在真正的耦合结构（非平凡统一），OT 距离 > 0 但有限。
- 若 ε → 0 时 π* 不收敛 ⟹ 边缘测度不满足凸性假设，fail-closed 触发。

**可判定性来源：**
π* 由 Sinkhorn 迭代唯一确定（熵惩罚保证）；支撑集是否为排列图可在多项式时间判定；d_OT = 0 等价于 μ₁ = μ₂（在 Polish 空间上）。三个判定都是可计算的，不是存在性陈述。

**这个实验的刚性意义：** 它把"两条线是否统一"从**语义判断**降为**OT 距离是否为零 + 耦合是否退化为排列**。如果 RIGID 为真，统一是**等号**（弱同构）；如果为假但距离有限，统一是**耦合结构**（有损但可审计）；如果 ε→0 不收敛，统一**不存在**，fail-closed 拒绝。
